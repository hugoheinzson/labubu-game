# Resources

Lege hier später deine iPad-spezifischen Assets (z. B. Egg PNG, Labubu-Sprites, Sounds) ab. Beim Import in Xcode kannst du diesen Ordner oder ein `Assets.xcassets`-Verzeichnis hinterlegen. Für eine reine iPad-App stelle in der finalen Xcode-Projektdatei sicher, dass nur `iPad` als unterstützte Gerätefamilie gesetzt ist.
